Desenvolvimento nativo para todos

React Native permite criar aplicativos verdadeiramente nativos sem comprometer a experiência do usuário. Ele fornece um conjunto essencial de componentes nativos independentes de plataforma, como `UIView` View, `UIView` e `UIView`, que se relacionam diretamente com os blocos de construção da interface do usuário nativa da plataforma. TextImage

Comece com o pé direito usando uma estrutura.

React Native traz o paradigma de programação React para plata formas como Android e iOS. Ele não prescreve como fazer rote amento ou como acessar cada uma das inúmeras APIs da platafo rma. Para criar um novo aplicativo com React Native, recomen damos um framework como o Expo.

Roteamento baseado em arquivos

Crie telas em pilha, modais, de gaveta e com abas com o mínimo de código repetitivo usando seu sistema de arquivos.

Utilize qualquer biblioteca, SDK ou código nativo.

Gere alterações nativas ou escreva seu próprio código nativo. Use mais de 50 módulos para criar seu aplicativo.

Ferramentas de desenvolvedor

Comece rapidamente com o Expo Go e, em seguida, continue com o expo-dev-client: um módulo que adiciona as ferra mentas do Expo a aplicativos que exigem alterações nativas.

Assista e aprenda

Assista às palestras da equipe React e aprenda a tirar o máximo proveito do React Native. Encontre as últimas novidades no Bluesky e no X.

Com suporte da Meta. Impulsionado pela comunidade.

A Meta lançou o React Native em 2015 e vem mantendo-o desde então.

Em 2018, o React Native tinha o segundo maior número de contribuidores entre todos os repositórios do GitHub. Hoje, o React Native é manti do por contribuiçõesde indivíduos e empresas do mundo todo, incluindo Callstack, Expo, Infinite Red, Microsoft e Software Mansion.

Nossa comunidade está sempre lançando novos projetos empolgantes e explorando plataformas além do Android e iOS com repositórios como React Native Windows, React Native macOS e React Native Web .

React Native está sendo usado em milhares de aplicativos, mas é provável que você já o tenha usado em um destes aplicativos: e muito mais.
